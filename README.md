# Aeonloom

A pixel-art god sandbox for the browser. Everything in it — images, animations, font, sounds, music — is generated by code in this repository.

**Play:** open `game/index.html` in a recent browser (no server needed), or host the `game/` folder on any static host.

**Rebuild:** `node tools/bake-all.js && node tools/build.js` (Node 22, no dependency).

Documents: BIBLE.md (design), STYLE.md (art direction), ARCHITECTURE.md, DECISIONS.md, TOOLS.md, PROVENANCE.md, REPORT.md, RESUME.md (current state).
