# Dustcrown

A pixel-art god sandbox for the browser: shape a world, seed its peoples and creatures, watch them build, pray, trade and fight, and step in as a god whenever you like. Every image, animation, font, sound and piece of music is generated by code in this repository; nothing is downloaded.

## Play
- Open **`game/index.html`** in a recent browser (Chrome, Edge, Firefox, Safari). No server, no install, no network.
- Or copy the **`game/`** folder as it is to any static host. It can be added to a phone or desktop as a web app (icons and manifest included).
- Title screen: *Enter this world* plays the world shown behind the menu; *New world* opens the generator; *Load a world* opens the save slots. English / French at the bottom left.
- `game/index.html?play` skips the title screen.

## Controls (all remappable in Options → Keys)
Mouse: left click = use the selected power or select, wheel = zoom, right or middle drag = move the map. Keyboard: `WASD` / arrows move, `Space` pauses, `1`–`7` choose a power category, `Esc` cancels, `C` cinema mode, `M` minimap, `L` map layers, `F3` numbers.
Options → *Provisional content* shows the content that is still placeholder quality (4 peoples, 32 animals, 17 monsters, 56 powers).

## Rebuild
`node tools/bake-all.js` regenerates every asset from its source in `tools/art/` and rebuilds `game/` (Node 22, Python 3 for the sound patches, no dependency). `node tests/run-all.js` runs every test (needs Playwright with Chromium).
